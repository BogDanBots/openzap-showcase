# Security policy

This repository is a documentation-only case study. It does not contain the
private OpenZap implementation, prompts, memory records, identity data,
credentials, or operational logs.

Please do not publish suspected credentials or private information in an issue
or pull request. Contact the repository owner through the
[BogDanBots GitHub profile](https://github.com/BogDanBots) with the affected
file, a minimal reproduction, and the impact. Never submit a seed phrase,
private key, API key, cookie, or RPC credential.

The case study is not an audit or a production security guarantee.
